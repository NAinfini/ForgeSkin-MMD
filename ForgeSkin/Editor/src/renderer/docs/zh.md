#! 入门

# ForgeSkin 人物皮肤 {#what}

ForgeSkin 把你的人物换成自己导入的人形模型，头发和裙摆按物理自己摆动。编辑器做两件事：**人物**（导入、骨骼匹配、第一人称手臂、头发与裙摆、挡板、材质、检查、导出，一步一份作品）和 **舞蹈**（把 VMD 动作、镜头、音乐做成游戏里 F9 播放的舞蹈）。

- **ForgeSkin 插件**装在 r2modman 的游戏配置档里。编辑器的 **应用** 会把它和它依赖的 ForgeCore 一起装好，不用自己下载。
- **作品**自动保存在编辑器的数据文件夹里，关掉软件也不会丢。
- 做好的皮肤可以打包成 `.forgeskin` 直接装进游戏，也可以导出成 Thunderstore 模组发给别人。

## 需要准备什么

- 装好 GTFO。右上角设置里能看到游戏文件夹；找不到时点 **选择文件夹**，选装有 `GTFO.exe` 的文件夹。
- 一个装了 BepInExPack_GTFO 的配置档（r2modman 或直接是游戏文件夹）。左栏顶部 **应用到：** 选它。
- 一个人形模型：`.glb`（Blender 导出时选 glTF Binary）或 `.vrm`（VRoid 等）。模型要带蒙皮和人形骨骼。

# 界面一览 {#editor}

1. **左栏。** 上方是 **作品**：所有人物皮肤一张卡，带它在配置档里的状态（只在编辑器 / 已装进档案 / 正在使用）。默认打开上次做的作品。
2. **步骤。** 左栏另一页是这次编辑的六个步骤：导入模型、骨骼匹配、第一人称手臂、头发与裙摆、材质、检查。按顺序走。
3. **中间 3D 视图。** 鼠标左键转动、右键平移、滚轮缩放。底部可以播放跳舞等动作，看头发和裙摆摆起来的样子。
4. **右栏。** 当前步骤的设置。
5. **顶栏。** 使用指南、设置（语言、游戏文件夹、数据文件夹、检查更新）、导出。

# 导入模型 {#import}

把 `.glb` / `.vrm` 拖进窗口，或点左栏 **＋新建**，或在第一步点 **选择模型**。

- VRM 里写好的骨骼、摆动骨和碰撞体会直接填好。
- 普通 glTF 会按骨架自动匹配骨骼；头发、裙摆会自动找出骨链加成弹簧组。
- 导入时会从模型测量身体挡板（挡板是头发和裙摆不能穿进去的身体表面）。
- 导入后所有编辑自动保存。

## 换模型

第一步点 **替换**。旧的骨骼匹配、弹簧、挡板都会按新模型重新来，作品名不变。

# 骨骼匹配 {#bones}

左边的人形图每个点是一个关节，绿=已匹配，红=缺必需关节（髋部），灰=没配（游戏里那条链保持静止，不报错）。点图上任意关节，在下面的搜索框选它的骨骼；自动匹配不对时点 **重新匹配**。

手指是单独的格子：三个小格代表一节指骨，点亮表示游戏会驱动它。手腕以下没有骨骼也不影响导出，只是游戏里手指不动。

# 第一人称手臂 {#arms}

游戏的第一人称视角会从模型上切出手臂。点 **查看手臂** 切到第一人称的样子，在列表里关掉不想显示的材质（常见是不想露出的身体或袖子）。

模型两只上臂都有骨骼时，游戏才会用你的模型当第一人称手臂；没有的话用游戏原版手臂。

# 头发与裙摆 {#springs}

- **＋ 添加弹簧组**：选一根骨头，从它往下自动成链。
- **自动识别**：按骨名和位置把头发（发根下的一束束）、裙摆（绕髋一圈的布）、尾巴找出来，各成一组。

每一组是一张卡片。卡片上可以：

- 看这一组里每一条 **发束**（骨链），点一条会在 3D 里高亮它，垃圾桶可以删掉单条；删掉最后一条等于删掉这组。
- 选 **预设**：长发、短发、裙摆、尾巴，决定下面所有参数的默认值。
- 拖参数滑杆。没碰过的参数跟着预设走；碰过的参数旁有重置按钮，点一下回到预设。
- 展开 **高级参数**：恢复力、风格牵引、惯性、方位限制、子步频率、迭代次数、长度修正次数、是否碰挡板 / 碰布料 / 自碰撞。

## 参数说明

| 参数 | 作用 |
| --- | --- |
| 刚度 | 每一节多想保持伸直。小=软，飘；大=硬，贴身。 |
| 阻尼 | 摆动多快停下来。小=晃得久，大=很快停。 |
| 重量 | 受重力和动作拖拽的程度。头发 0.3–0.8，裙摆 0.6–1.2。 |
| 重力 | 往下垂多少。0 = 不垂（只跟动作晃）。 |
| 半径 | 这一串的粗细，用来和挡板保持距离，也用于自碰撞。 |
| 弯曲限制 | 相邻两节最多转多少度。小=整串硬成一条，大=自由。 |
| 恢复力 | 想回到静止形状的力。长马尾太爱乱甩时加上去。 |
| 风格牵引 | 把每一节往上一节的方向拉，保持发型轮廓。 |
| 惯性 | 跟随身体加减速的滞后感。大=更容易被甩起来。 |
| 方位限制 | 每一节偏离它那一圈方向的最大角度，防止头发转到脸前或穿进脑袋。 |
| 子步频率 | 物理每秒算多少次。越高越稳越费性能（60–480 Hz）。 |
| 迭代次数 | 每次子步里约束迭代几次。高=更硬更稳，费性能。 |
| 长度修正 | 把被拉长的骨头拉回原长，防止越甩越长。 |
| 碰挡板 / 碰布料 / 自碰撞 | 是否和身体挡板、别的弹簧组、自己相交的部分碰撞。 |

## 小幅度动作就乱甩？

越长的链、每一节越短，越容易自己抖起来（MMD 的双马尾常见，一节只有 1 厘米）。处理办法，按效果顺序：

1. 删掉链里过密的骨头（两条发束只保留第一节和最后一节试试）；
2. 加大 **阻尼** 和 **恢复力**；
3. 加大 **子步频率**（例如 120 Hz）看是否稳定，稳定后可以再降回来；
4. 降低 **惯性**。

# 挡板 {#colliders}

挡板是头发和裙摆不能穿进去的身体表面。默认用 **身体表面**：从模型自己的三角面量出来的精确碰撞体。列表里可以关掉某些材质（比如超短裙不想要挡板），点 **重新测量** 重来。

如果模型自带碰撞体（VRM），会自动用文件里的；想改用自动的，点 **改回自动挡板**。

**身体胶囊** 是按关节量出的简化碰撞体，比表面省一点性能，但更容易从两腿之间漏过去。一般用默认的表面就好。

# 材质 {#materials}

这里列出模型的全部材质。目前游戏里统一使用受光材质，列表只用于确认哪些材质会参与挡板和手臂的开关。

# 检查与导出 {#export}

第六步 **检查** 确认必需关节都有骨骼，然后：

- 顶栏 **导出 ▸ 导出模组包**：填名字、版本、说明、图标，导出成 Thunderstore 模组 zip 发给别人；
- 同一窗口里的 **导出皮肤包**：只导出 `.forgeskin` 文件。

# 应用到游戏 {#apply}

作品卡上的 **应用**：打包并装进 **应用到：** 选的配置档，游戏里立刻换上（游戏开着也行，插件几秒内热加载）。第一次应用会自动装好 ForgeSkin 插件。

**装进档案**：只装进档案，不让游戏立刻使用它（之后可以在游戏大厅的皮肤按钮里选）。

# 舞蹈 {#dance}

顶栏中间切到 **舞蹈**，就能把一段 MMD 舞蹈做成游戏里按 F9 播放的样子：动作、镜头、音乐、表情各选一个文件，转成游戏用的格式，再装进配置档。

编辑器会启动本机的 **Blender**（4.2 以上，装好后自动找到；找不到时在第一步里填 `blender.exe` 的位置）配上 mmd_tools 来算动作——这和以前手动烘焙出来的舞蹈是同一套结果。

## 需要准备什么

- 一个 MMD 动作 `.vmd`（起舞）。可选：镜头 `.vmd` 或已经烘好的 `.cam`、音乐（`.wav`/`.mp3` 等）。表情不用单独准备：动作里带的表情（眨眼、口型、眼神）会自动识别。
- 装好并**手动**装好 **BepInExPack_GTFO** 和 **GTFO_API 0.6.1** 的配置档：这两个是基础依赖，编辑器不替你装。ForgeCore、ForgeSkin 和跳舞插件由编辑器自己带、自己装。

## 第 1 步 导入

舞蹈页的三个步骤（**1. 动作** / **2. 剪辑** / **3. 导出**）竖排在右边栏靠窗口边缘的标签条里（图标下写着名字，鼠标停上去显示全名），点哪个就切到哪一步。在 **1. 动作** 的 **我的舞蹈** 里点 **＋新建舞蹈**，起个名字（游戏里看到的就是这个名字；想改回来，双击 **我的舞蹈** 里的名字就能就地改，改的也是同一个名字），然后：

1. **动作** 选 `.vmd`，点 **转换成舞蹈**。时间长短取决于动作：三四分钟的舞蹈大约要一分钟。
2. **音乐** 选歌。游戏只认 `.wav`，编辑器导出时会自动转成 PCM WAV。
3. **镜头** 选镜头 `.vmd` 或已经烘好的 `.cam`，再决定要不要 **使用镜头**。不开就是游戏原本的镜头；镜头的时长可以比舞蹈短，短了就用最后一帧停住。
4. **表情** 动作 VMD 里自带的表情（眨眼、口型、眼神等，作者常用的 MMD 表情名）会自动识别出来，导出时写成游戏用的 `.face`；识别到的表情名会列在这里，可以关掉「导出动作里的表情」。也可以另外选一个已经烘好的 `.face`，选了就只用它。

## 第 2 步 动作

- **剪辑**：三条轨道（运镜、MMD 动作、音乐）各是一排片段。点一下选中片段，拖片段两头裁切、拖片段中间整段挪位置；工具栏的剪刀（或 Ctrl+B）在播放头处把它切成两段，垃圾桶（或 Delete）删掉选中的那段；改错了用 Ctrl+Z 撤销、Ctrl+Shift+Z（或 Ctrl+Y）重做，工具栏左上两个箭头也一样，最多记 100 步。同一条轨道上的片段**不会叠在一起**：挪或拉到头就停在前一段的末尾 / 后一段的开头。开着磁吸（默认开）时，片段两端还会吸附到 0:00、播放头和别的片段的边上，吸附时画一条橙线。拖动时中间的画面和音乐一起跟着走。
- **放大时间轴**：工具栏右侧的 **− / 1.0× / ＋**，或者按住 Ctrl 滚滚轮，时间轴会横向拉长（最多 32 倍），适合逐帧对点。拉长以后用滚轮左右平移，拖播放头或播放时画布会自动跟着走；缩回 1.0× 就是整条舞蹈铺满窗口。拉长到超过窗口宽度时，轨道最底下会出现一条横向滑动条：拖它左右看，点滑动条空白处直接跳过去，滚轮照样能平移。
- **片段参数**：点轨道上的一个片段，右边栏就会显示这个片段的参数。音乐片段有 **音量**（0–200%，写进导出的 `.wav`）和 **淡入 / 淡出**（秒）；MMD 动作和运镜片段有 **速度**（0.25–3×，变慢或变快都保持片段在时间轴上的长度，超出素材的部分停在最后一帧）。参数改完立刻生效，预览和导出是同一套计算，重开工程也会记住。
- **音量**：游戏里播放的音量（默认 30%）。

## 中间的画面

按住左键拖动是转视角，滚轮放大缩小，右键拖动是平移——跟人物页一样随便看。添加了镜头以后，画面左上角可以切到 **镜头视角**，看到的就是游戏里运镜后的画面；切回 **自由视角** 继续自己看。镜头视角旁边还有一个取景框按钮：按下后中间画面会出现一个 16:9 的框，框外压暗，框里就是游戏实际拍到的范围（中间画面不是 16:9，不按这个按钮会比游戏多看到一圈）。动作里带的表情会跟着时间实时演出来（眨眼、口型、眼神），和导出后游戏里看到的一致。画面最底下是播放条：点进度条上任意一处就从那里开始放，中间的圆钮暂停/继续，左右两边分别退 5 秒和进 5 秒，键盘 ← → 也同样前后跳 5 秒。空格键也能暂停和继续；一首跳完以后再按播放（或空格），会从 0:00 重新放一遍。

## 第 3 步 导出

**导出** 会把成品写进这个作品的 `out` 文件夹：`名字.dance`、`名字.cam`、`名字.wav`。

**应用到游戏** 一步装好：把舞蹈文件放进配置档的 `BepInEx\plugins\GtfoMmdDance\Dances\`，同时装好 ForgeCore、ForgeSkin 和跳舞插件。缺 BepInExPack_GTFO 或 GTFO_API 时会提示你先装。装完进游戏按 **F9**，列表里就有它——不用重启游戏。

> 舞蹈是按**文件名**认的，联机时靠文件的哈希对暗号：发给别人的 `.dance` 要一模一样（用同一个动作、同一台电脑转出来的才算一致）。

# 常见问题 {#faq}

- **游戏里看不见人物？** 确认插件版本（左栏配置档菜单里显示）和编辑器一致；应用一次会自动更新。
- **头发穿模？** 先确认挡板开的是 **身体表面** 并且材质没被关掉；再加大半径或降低刚度。
- **人物浮空 / 陷地？** 第一步的 **身高** 微调；模型脚底不在原点时，先在 Blender 里对齐。
- **找不到自己的作品？** 作品都在设置里的数据文件夹 `autosave\character` 下。
